# agro_esep_python

Решатель задачи оптимизации животноводства (1.1)-(1.6) — FastAPI-сервис
без базы данных и без состояния. Подробности архитектуры: план реализации
проекта (артефакт «AgroESEP — план реализации v2»).

## Запуск локально

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements-dev.txt
pytest
uvicorn app.main:app --reload
```

`GET /v1/health` — проверка живости.
`POST /v1/solve` — расчёт, схема запроса/ответа в `app/schemas.py`.

## Контрольный пример

`tests/fixtures.py` — свой, внутренне согласованный тестовый набор
(не те цифры, что упоминались в анализе проекта — исходные параметры того
примера не передавались, только итоговый результат). Как только институт
передаст реальную нормативную базу и контрольный пример с известным
вручную ответом — фикстура и тест `test_reference_case.py` заменяются на них.
